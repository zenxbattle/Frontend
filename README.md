# frontend

react + typescript + vite frontend for zenxbattle. includes a monaco-based code editor with multi-file support, a problem-solving playground with test case runner, and standard auth/profile ui.

## env vars

| var | default | description |
|-----|---------|-------------|
| vite_api_base_url | http://localhost:7000 | api gateway url |

## features

- monaco code editor with syntax highlighting and multi-file tabs
- standalone code compiler with output panel and execution time
- problem-solving playground with run/submit and test case results
- code hints via gemini api integration
- dark theme throughout
